                         SETS & RELATIONS


1) SET NOTATION AND SUBSET FACTS
   A = {x : P(x)}
   x ∈ A        ; x belongs to A
   x ∉ A        ; x does not belong to A
   ∅            ; empty set
   U            ; universal set

   A ⊆ B  iff  (x ∈ A ⇒ x ∈ B)
   A = B  iff  A ⊆ B and B ⊆ A

   Facts:
   • ∅ ⊆ A for every set A
   • A ⊆ A
   • if A ⊆ B and B ⊆ C, then A ⊆ C

   Important identities:
   A − B = A ∩ B′
   A′ = U \ A
   (A′)′ = A
   A ∩ A′ = ∅
   A ∪ A′ = U


2) NUMBER OF SUBSETS, PROPER SUBSETS, POWER SET
   If |A| = n, then:
   • total subsets = 2^n
   • proper subsets = 2^n − 1
   • power set P(A) has |P(A)| = 2^n

   Also:
   • non-empty subsets = 2^n − 1
   • singleton subsets = n
   • 2-element subsets = nC2


3) SET IDENTITIES AND DE MORGAN'S LAWS
   A ∩ B = {x : x ∈ A and x ∈ B}
   A ∪ B = {x : x ∈ A or x ∈ B}
   A \ B = A ∩ B′

   Laws:
   A ∪ ∅ = A             A ∩ U = A
   A ∩ ∅ = ∅             A ∪ U = U
   A ∪ A = A             A ∩ A = A
   A ∪ B = B ∪ A         A ∩ B = B ∩ A

   Distributive laws:
   A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
   A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)

   De Morgan's laws:
   (A ∪ B)′ = A′ ∩ B′
   (A ∩ B)′ = A′ ∪ B′

   General form:
   (∪ A_i)′ = ∩ A_i′
   (∩ A_i)′ = ∪ A_i′


4) INCLUSION–EXCLUSION
   For two sets:
   |A ∪ B| = |A| + |B| − |A ∩ B|

   For three sets:
   |A ∪ B ∪ C|
   = |A| + |B| + |C|
     − |A ∩ B| − |B ∩ C| − |C ∩ A|
     + |A ∩ B ∩ C|

   Also:
   |A \ B| = |A| − |A ∩ B|
   |A Δ B| = |A| + |B| − 2|A ∩ B|


5) CARTESIAN PRODUCT CARDINALITY
   A × B = {(a, b) : a ∈ A, b ∈ B}

   If |A| = m and |B| = n, then:
   |A × B| = mn

   Therefore:
   |A × A| = n^2
   |A × B × C| = |A||B||C|

   Also:
   A × (B ∪ C) = (A × B) ∪ (A × C)
   A × (B ∩ C) = (A × B) ∩ (A × C)


6) DOMAIN, CODOMAIN, RANGE AND INVERSE RELATION
   A relation R from A to B is a subset of A × B.

   Domain(R) = {a ∈ A : ∃ b ∈ B with (a,b) ∈ R}
   Codomain(R) = B
   Range(R) = {b ∈ B : ∃ a ∈ A with (a,b) ∈ R}

   Inverse relation:
   R⁻¹ = {(b, a) : (a, b) ∈ R}

   Thus:
   Domain(R⁻¹) = Range(R)
   Range(R⁻¹) = Domain(R)


7) NUMBER OF RELATIONS
   Let |A| = n.

   Total relations on A:
   2^(n^2)

   Reflexive relations:
   2^(n(n−1))

   Irreflexive relations:
   2^(n(n−1))

   Symmetric relations:
   2^n · 2^(n(n−1)/2)
   = 2^(n(n+1)/2)

   Antisymmetric relations:
   2^n · 3^(n(n−1)/2)

   If relation is from A to B with |A| = m, |B| = n:
   total relations = 2^(mn)


8) DEFINITIONS OF RELATION TYPES
   Reflexive:
   (a,a) ∈ R for every a ∈ A

   Irreflexive:
   (a,a) ∉ R for every a ∈ A

   Symmetric:
   (a,b) ∈ R ⇒ (b,a) ∈ R

   Asymmetric:
   (a,b) ∈ R ⇒ (b,a) ∉ R

   Antisymmetric:
   (a,b) ∈ R and (b,a) ∈ R ⇒ a = b

   Transitive:
   (a,b) ∈ R and (b,c) ∈ R ⇒ (a,c) ∈ R

   Quick distinction:
   symmetric ≠ antisymmetric
   asymmetric ⇒ irreflexive
   reflexive + symmetric + transitive = equivalence relation
   reflexive + antisymmetric + transitive = partial order


9) EQUIVALENCE RELATIONS AND EQUIVALENCE CLASSES
   A relation ~ on A is an equivalence relation iff:
   • reflexive
   • symmetric
   • transitive

   Equivalence class of a:
   [a] = {x ∈ A : x ~ a}

   Properties:
   • a ∈ [a]
   • [a] = [b] iff a ~ b
   • if [a] ≠ [b], then [a] ∩ [b] = ∅
   • union of all equivalence classes = A

   Therefore, equivalence classes partition A.


10) PARTIAL ORDERS, POSETS, MIN/MAX, LEAST/GREATEST
   Partial order ≤ on A:
   • reflexive
   • antisymmetric
   • transitive

   Poset = (A, ≤)

   Minimal element:
   no element is strictly smaller than it

   Maximal element:
   no element is strictly larger than it

   Least element:
   x ≤ a for every a ∈ A

   Greatest element:
   a ≤ y for every a ∈ A

   Important:
   least ⇒ minimal
   greatest ⇒ maximal
   minimal need not be least
   maximal need not be greatest
   least/greatest, if they exist, are unique


11) TEN COMMON JEE ADVANCED TRAPS
   1. ∅ ⊆ A always; never say “∅ ∈ A” unless given.
   2. A − B = A ∩ B′, not B − A.
   3. A ⊆ B and B ⊆ A ⇒ A = B, not just same size.
   4. A × (B ∪ C) = (A × B) ∪ (A × C).
   5. Reflexive means every element relates to itself.
   6. Symmetric and antisymmetric are different.
   7. Asymmetric ⇒ irreflexive, but converse not always.
   8. [a] = {x : x ~ a}, not “same property / same size”.
   9. Minimal ≠ least; maximal ≠ greatest.
   10. Inclusion–exclusion must include triple intersection term.
